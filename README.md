
# Интернет-магазин

Этот проект представляет собой интернет-магазин, который будет дорабатываться на каждом уроке в течение курса. В конце курса проект станет полноценным приложением, готовым для добавления в ваше портфолио.

## Установка и настройка

### Задание 1. Настройка проекта

1. **Создание проекта:**
   - Создайте новую директорию для проекта.
   - Настройте виртуальное окружение (например, используя venv).
   - Установите Django и инициализируйте новый проект внутри этой директории.

2. **Контроль версий:**
   - Добавьте файл `.gitignore` для исключения файлов виртуального окружения, миграций, временных файлов и т. д.
   - Используйте методологию GitFlow:
     - Создайте ветки `main` и `develop`.
     - Создавайте отдельные ветки для выполнения домашних заданий.

3. **Запуск проекта:**
   - Активируйте виртуальное окружение.
   - Перейдите в корневую директорию проекта и выполните: python manage.py runserver
     


### Задание 2. Создание и настройка приложения

1. **Создание приложения:**
   - Создайте новое приложение под названием `catalog` внутри вашего проекта.

2. **Регистрация приложения:**
   - Добавьте `catalog` в список `INSTALLED_APPS` в файле настроек `settings.py`.

3. **Маршрутизация:**
   - Настройте маршрутизацию для нового приложения, добавив соответствующие URL-адреса в файлы `urls.py`.

### Задание 3. Создание шаблонов

1. **HTML-шаблоны:**
   - Подготовьте два HTML-шаблона: `home.html` и `contacts.html`.
   - Для стилизации используйте CSS-фреймворк Bootstrap.

2. **Структура шаблонов:**
   - Шаблоны должны быть расположены в директории `templates/catalog/`.

### Задание 4. Реализация контроллеров

1. **Контроллеры:**
   - Создайте контроллер для отображения домашней страницы (`home`).
   - Создайте контроллер для отображения страницы с контактной информацией (`contacts`).

2. **Настройка маршрутизации:**
   - Настройте маршрутизацию в файле `urls.py` для контроллеров `home` и `contacts`.

## Планы и развитие проекта

Проект будет расширяться и улучшаться на протяжении курса. Не пропускайте выполнение домашних заданий, чтобы к завершению курса у вас был полностью функциональный интернет-магазин.
